# Reporting a security problem

Please do **not** open a public issue for a security problem.

Instead, use GitHub's private reporting: the **Security** tab of this
repository → **Report a vulnerability**. Describe what you found and how to
reproduce it. We aim to reply within 7 days.

Things we especially want to hear about:

- a way to receive another shop's print orders or files;
- a way to use the Printer App's ID or secret key from another program or computer;
- the automatic update installing something that PrintSetu did not publish;
- anything that lets a document or print job run code on the shop's computer.

Please give us a reasonable time to fix a problem before you talk about it
publicly.
